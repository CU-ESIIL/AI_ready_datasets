# Implementation module map

Generated from module docstrings and public definitions. The three scientific stages remain independently callable; CLI/orchestration only compose them.

| Module | Responsibility | Public functions and classes |
| --- | --- | --- |
| [adapters](https://github.com/CU-ESIIL/AI_ready_datasets/blob/main/src/dataset_prototype/adapters.py) | Local mock transport and an honest, unavailable external MESA boundary. | `AccessClient`, `MESAClient`, `MockMESAClient` |
| [agents](https://github.com/CU-ESIIL/AI_ready_datasets/blob/main/src/dataset_prototype/agents.py) | Bounded, deterministic local stand-ins for future OpenClaw workers. | `DiscoveryAgent`, `SemanticAgent`, `HarmonizationAgent`, `QAAgent` |
| [cli](https://github.com/CU-ESIIL/AI_ready_datasets/blob/main/src/dataset_prototype/cli.py) | CLI for reproducible fixture runs, independent stages, schema and review. | `main` |
| [consensus](https://github.com/CU-ESIIL/AI_ready_datasets/blob/main/src/dataset_prototype/consensus.py) | Bounded specialist dialogue over metadata; no source-data reader is accepted. | `negotiate` |
| [contracts](https://github.com/CU-ESIIL/AI_ready_datasets/blob/main/src/dataset_prototype/contracts.py) | Immutable, validated inter-module contracts. JSON schemas are exportable. | `digest`, `Contract`, `EvidenceKind`, `SemanticEvidence`, `ConceptCandidate`, `SourceSemantics`, `Support`, `Rights`, `Variable`, `Metadata`, `ScientificRequest`, `SourceResource`, `DiscoveryCandidate`, `DiscoveryResult`, `SemanticMapping`, `Operation`, `Proposal`, `AgentReview`, `recipe_content_digest`, `HarmonizationRecipe`, `QAReport`, `HumanDecision`, `RawObservation`, `ProvenanceRecord`, `HarmonizedObservation`, `Representation`, `TrackConfig` |
| [discovery](https://github.com/CU-ESIIL/AI_ready_datasets/blob/main/src/dataset_prototype/discovery.py) | Discovery knows requirements and source contracts, never encoders. | `relevant`, `run` |
| [embedding_dataset](https://github.com/CU-ESIIL/AI_ready_datasets/blob/main/src/dataset_prototype/embedding_dataset.py) | Streaming MOSAIKS dataset publication and bounded downstream verification. | `write_dataset`, `verify_dataset`, `predict_vectors` |
| [harmonization](https://github.com/CU-ESIIL/AI_ready_datasets/blob/main/src/dataset_prototype/harmonization.py) | Scientific review and allow-listed deterministic execution, independent of MESA. | `assess`, `authorize`, `run`, `transformed_uncertainty` |
| [harmonized_rasters](https://github.com/CU-ESIIL/AI_ready_datasets/blob/main/src/dataset_prototype/harmonized_rasters.py) | Bounded raster assembly from immutable harmonization outputs, never raw DN. | `RasterContext`, `authorize_context`, `assemble_patch`, `harmonize_window` |
| [model_agents](https://github.com/CU-ESIIL/AI_ready_datasets/blob/main/src/dataset_prototype/model_agents.py) | Real model-backed bounded roles. Models see evidence and emit JSON only. | `source_evidence`, `CandidateChoice`, `SemanticJudgment`, `RecipePlan`, `Critique`, `AgentTrace`, `OllamaBackend`, `ModelDiscoveryAgent`, `ModelSemanticAgent`, `ModelHarmonizationAgent`, `ModelQAAgent`, `propose_snapshot` |
| [mosaiks](https://github.com/CU-ESIIL/AI_ready_datasets/blob/main/src/dataset_prototype/mosaiks.py) | MOSAIKS empirical random convolutional features over harmonized raster outputs. | `MOSAIKSSpec`, `HarmonizedRasterPatch`, `file_digest`, `array_digest`, `validate_patch`, `target_schema_digest`, `MOSAIKSEncoder` |
| [mosaiks_pipeline](https://github.com/CU-ESIIL/AI_ready_datasets/blob/main/src/dataset_prototype/mosaiks_pipeline.py) | Thin composition: approved harmonization stream → MOSAIKS → dataset. | `RasterLayout`, `encoder_contract`, `plan_rasters`, `run`, `demo` |
| [neon](https://github.com/CU-ESIIL/AI_ready_datasets/blob/main/src/dataset_prototype/neon.py) | Authenticated official NEON data-file access, without guessing sensor support. | `NEONClient` |
| [network](https://github.com/CU-ESIIL/AI_ready_datasets/blob/main/src/dataset_prototype/network.py) | Bounded HTTP transport; no credential values in persisted request evidence. | `AccessError`, `CredentialRedirectGuard`, `request_bytes`, `request_json` |
| [openclaw_backend](https://github.com/CU-ESIIL/AI_ready_datasets/blob/main/src/dataset_prototype/openclaw_backend.py) | OpenClaw llm-task transport using the isolated Verde runtime. | `OpenClawBackend` |
| [openclaw_runtime](https://github.com/CU-ESIIL/AI_ready_datasets/blob/main/src/dataset_prototype/openclaw_runtime.py) | Isolated, version-matched OpenClaw + Verde runtime management. | `read_verde_settings`, `runtime_config`, `start_runtime`, `stop_runtime`, `runtime_status` |
| [orchestration](https://github.com/CU-ESIIL/AI_ready_datasets/blob/main/src/dataset_prototype/orchestration.py) | Thin composition of discovery, harmonization and representation modules. | `load_track`, `write`, `run` |
| [provenance](https://github.com/CU-ESIIL/AI_ready_datasets/blob/main/src/dataset_prototype/provenance.py) | PROV-inspired JSON-LD 1.1 export; no graph service or network resolution. | `export` |
| [real_data](https://github.com/CU-ESIIL/AI_ready_datasets/blob/main/src/dataset_prototype/real_data.py) | Actual STAC discovery/windowed Sentinel reads and auditable local snapshots. | `EvidenceFile`, `Snapshot`, `save_snapshot`, `SnapshotClient`, `acquire_sentinel`, `read_sentinel_pixel` |
| [representations](https://github.com/CU-ESIIL/AI_ready_datasets/blob/main/src/dataset_prototype/representations.py) | Local modality-specific scalar encoders with explicit preprocessing. | `run`, `batches` |
| [review](https://github.com/CU-ESIIL/AI_ready_datasets/blob/main/src/dataset_prototype/review.py) | Deterministic synthesis of evidence-bound specialist findings. | `source_set_digest`, `synthesize`, `validate_qa_references` |
| [review_contracts](https://github.com/CU-ESIIL/AI_ready_datasets/blob/main/src/dataset_prototype/review_contracts.py) | Versioned evidence-first review contracts, separate from legacy dialogue votes. | `Domain`, `Status`, `Evidence`, `ReviewFinding`, `SpecialistReview`, `ReviewReport`, `RunManifest` |
| [science](https://github.com/CU-ESIIL/AI_ready_datasets/blob/main/src/dataset_prototype/science.py) | A descriptive fixture comparison, never evidence of predictive performance. | `summarize` |
| [scoped_review](https://github.com/CU-ESIIL/AI_ready_datasets/blob/main/src/dataset_prototype/scoped_review.py) | Independently callable metadata review; the backend has no source-access tools. | `ReviewBundle`, `QASynthesis`, `review_metadata` |
| [semantic_benchmark](https://github.com/CU-ESIIL/AI_ready_datasets/blob/main/src/dataset_prototype/semantic_benchmark.py) | Bounded, offline metadata diagnostics; never scientific equivalence or ontology adoption. | `BenchmarkConfig`, `read_metadata_json`, `compute`, `run` |
| [semantic_discovery](https://github.com/CU-ESIIL/AI_ready_datasets/blob/main/src/dataset_prototype/semantic_discovery.py) | Module 1: preserve declared semantics and retrieve candidates; never approve mappings. | `source_metadata_digest`, `normalized_evidence`, `stac_evidence`, `enrich` |
| [semantic_resources](https://github.com/CU-ESIIL/AI_ready_datasets/blob/main/src/dataset_prototype/semantic_resources.py) | Validated landscape inventory and portal-independent concept-candidate retrieval. | `SemanticResource`, `AssessmentContent`, `ResourceAssessment`, `load_inventory`, `load_assessments`, `NamespaceBinding`, `ConceptRecord`, `SemanticResolver`, `SemanticResourceRegistry` |
| [storage](https://github.com/CU-ESIIL/AI_ready_datasets/blob/main/src/dataset_prototype/storage.py) | Content-addressed immutable JSON artifacts shared safely between tracks. | `cached` |
| [stream_contracts](https://github.com/CU-ESIIL/AI_ready_datasets/blob/main/src/dataset_prototype/stream_contracts.py) | Metadata control plane and bounded streaming data plane contracts. | `StreamBinding`, `EncoderSpec`, `StreamPlan`, `StreamSample`, `AgentMessage`, `SpecialistFinding`, `ReviewVote`, `RecipeBindingProposal`, `RecipeDraft`, `ConsensusReport` |
| [stream_rasters](https://github.com/CU-ESIIL/AI_ready_datasets/blob/main/src/dataset_prototype/stream_rasters.py) | Upstream native raster access → reviewed harmonization output stream. | `sentinel_harmonized_tiles` |
| [stream_sources](https://github.com/CU-ESIIL/AI_ready_datasets/blob/main/src/dataset_prototype/stream_sources.py) | Metadata-only Sentinel planning and lazy native-pixel access without snapshots. | `validate_assets`, `plan_sentinel`, `validated_native`, `sentinel_samples` |
| [streaming](https://github.com/CU-ESIIL/AI_ready_datasets/blob/main/src/dataset_prototype/streaming.py) | Backpressured window → harmonization → encoder → JSONL sink. | `preflight`, `stream_embed` |
