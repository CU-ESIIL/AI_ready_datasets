# Pipeline state report

The 21 October 2026 visual report explains the scientific problem, current
architecture, evidence and remaining work for scientists and collaborators.
It contains 38 pages and 34 reproducibly generated figures, with an editable
narrative, component inventory, input hashes, test evidence and package versions.

[Read the PDF in the repository](https://github.com/CU-ESIIL/AI_ready_datasets/blob/main/output/pdf/AI_ready_pipeline_state_report.pdf)
or [inspect the report source and rebuild instructions](https://github.com/CU-ESIIL/AI_ready_datasets/tree/main/reports/pipeline_state).
These repository links become available after the local changes are published.

The report follows a retained real Sentinel observation but does not claim an
approved real-data embedding release. Its successful CubeDynamics/MOSAIKS
experiment uses generated windows and fixture approval. Ontology and dataset
scores are metadata diagnostics; missing scientific measurements remain explicit.

Verification: 203 tests passed in the Python 3.12 CubeDynamics environment;
175 passed and one optional module skipped in the core environment. The report
keeps these scopes separate from scientific validity and production readiness.
