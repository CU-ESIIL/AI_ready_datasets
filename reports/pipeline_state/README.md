# Pipeline state report — 21 October 2026

The report distinguishes historical real Sentinel evidence, historical model
reviews, the fresh generated CubeDynamics/MOSAIKS run and planned scientific work.
It does not acquire source data, invoke models or confer scientific approval.

- Final PDF: `../../output/pdf/AI_ready_pipeline_state_report.pdf`
- Editable narrative: `report.json` and `report.md` (generated by `build_report.py`)
- Figure/narrative definitions: `build_report.py`

- Full operation/maturity tables: `data/operations.json`, `tables/maturity.json`

## Rebuild from the retained evidence snapshot

Use Python 3.12, install this repository with its `dev,cubedynamics` extras, then
install `reports/pipeline_state/requirements.txt`. From the repository root:

```sh
MPLCONFIGDIR=/tmp/ai-ready-report-mpl python reports/pipeline_state/build_report.py
python reports/pipeline_state/verify_report.py
pdftoppm -scale-to 1000 -png output/pdf/AI_ready_pipeline_state_report.pdf /tmp/report-page
```

The report builder reads the committed evidence snapshot; ignored historical run
folders are unnecessary for that build. Its figures also read the canonical
inventory, current registry-test source and the existing attributed NASA cover.
Matplotlib SVG metadata and PDF creation timestamps can vary: regeneration is
analytically reproducible, not promised byte-for-byte identical. Inspect the PDF
visually after changes. The builder rejects text blocks that exceed layout bounds.

## Refresh the audit (explicit local historical inputs required)

`audit.py` reads actual repository code, exported schemas, existing benchmark
Parquet files, a selected historical Sentinel pixel/review and a fresh generated
CubeDynamics run. Those original ignored artifacts are not recreated or silently
replaced if absent. Initial collection used:

```sh
python -m pytest -q --junitxml=reports/pipeline_state/data/tests.xml
python -m dataset_prototype.cli cubedynamics-demo --output run/cubedynamics-verified
python reports/pipeline_state/audit.py
python reports/pipeline_state/build_report.py
```

Choose a new output directory if the demonstration already exists; update the
explicit audit inputs accordingly. The snapshot includes one historical retained
pixel as report evidence, not a new download or raster dataset. Model findings in
`review_summary.json` are preserved judgments, including potentially mistaken ones;
they are not execution authority. The source record and reviewed Sentinel scene
have different acquisition dates and are explicitly distinguished in the report.

## Interpretation and scope

Inventory coverage weights and dataset field-presence scores are project metadata
diagnostics. They are not ontology quality, semantic equivalence, ecological
compatibility or independent validation. Potential/diversity/depth/remote throughput
are unmeasured. Status/maturity assignments are editorial assessments linked to
source/tests. WORKING means a bounded local capability, not production readiness.
The baseline audit commit identifies scientific implementation; the report and
integration-documentation changes were uncommitted at audit time.
