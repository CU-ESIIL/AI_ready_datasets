# Controlled agent protocol v2 — frozen synthetic pilot

Frozen on 20 November 2026 before the retained v2 mock run. The 29 public synthetic
questions are development/controlled-mechanism cases, not a hidden generalization
set. The separate held-out configuration is inert pending independently authored
new templates/events. No real wildfire observations, neural encoders, forecasting,
source downloads or runtime scientific programming are part of this milestone.

## Questions and contrasts

H1: richer metadata may improve operation selection. H2: it may improve recognition
of insufficient information. H3: adaptive representation access may improve coverage
compared with fixed views, including a strong fixed-R0 and explicit rule router.
H4: routing may introduce inference/tool/selection costs; correctness and cost are
separate outcomes. None is assumed true, and a simulator cannot test LLM hypotheses.

Fixed R0/R1/R2 × M0/M1/M2 gives 261 cells. Adaptive (all views) × M0/M1/M2 gives
87. Total: 348 cells, three repetitions = 1,044 episodes, one cold application-cache
policy per episode. A separate deterministic baseline matrix has 348 episodes:
fixed R0/R1/R2 and operation-contract routing. Repetitions are protocol replays for
the mock, not independent model samples or scientific fires.

## Source and information boundary

Reuse the complete hash-verified milestone-1 snapshot and pinned external Fire VASE
operation file. No new PCA fitting or changed answer keys. Alias fire IDs and source
observation IDs; do not expose `Task`, its ID/family, operation label, tolerance,
answerability map, required-observation list or reference answer. Model-facing
questions retain the existing wording, including explicit missing/zero cases;
wording hints are a limitation, not hidden new evidence of generalization.

The deterministic renderer exposes the same scientific data for a given interface
across metadata conditions. Common information includes JSON syntax, operation IDs,
argument types, representation formats, required unit safety, alias identifiers,
null semantics and budgets. R0 retains dates/cumulative values; R1 retains profiles
and traits; R2 retains coordinates. All retain the existing source-ID/validated
primary-eligibility sidecar. That metadata legitimately supports sequence length;
it is not a per-question answerability label.

M0 supplies parsing necessities; M1 adds descriptive scientific definitions; M2 adds
machine-actionable general scientific preconditions and representation limitations.
General contracts are allowed; item-specific instructions and expected values are
not. Rich error messages from milestone 1 stay private. All conditions receive the
same rejection codes and operation result envelope: value/no_result, declared unit,
approximation flag and opaque evidence IDs. `inspect` can only repeat a permitted
view's public data. It cannot retrieve source files, hidden grading information or
an unauthorized view. Metadata does not add executable operations or budget.

## Decisions and authority

Models return JSON proposals: select, inspect, call, answer-by-result-reference, or
abstain. A separate deterministic controller checks schema, offered IDs, parameters,
scientific preconditions, representation authorization and budgets. Runtime source
IDs and targets remain fixed to the caller-offered case. No native model tools,
Python, shell, SQL, arbitrary import, formula, file path or external fetch is exposed.
Scientific numerical answers come only from deterministic results. Optional copied
values must exactly match their referenced result; evidence citations are mandatory.
An accidentally correct unsupported number is rejected and counted. OpenClaw
transport enforces a JSON object; the full action schema remains in the prompt and
in the deterministic validator, allowing unknown-but-JSON actions to reach uniform
rejection/recovery rather than being mislabeled transport failures. A rejected
proposal may be followed by a new proposal within budget; software never repairs
malformed or truncated output. The exact rejected response is retained.

The controller is authorized only for these synthetic tests; it is not a human
scientific approval mechanism. Production recipes, human decisions and model vetoes
are unchanged. Original source/audit/proposal and milestone-1 outputs remain intact.

## Frozen execution bounds

`config/agent-mock-frozen-v2.json` fixes the simulator identity, evidence file,
three repetitions, ordering seed 20261120, temperature 0, six steps, four tool
attempts and 120 seconds per episode, 48,000 prompt bytes and 10,000 provider calls
per run. Token ceilings are checked against reported usage; unknown usage is not
claimed zero or enforceable as an exact total. Step/byte/output/time limits remain.
Mock use has no LLM token measurement. OpenClaw's plugin does not expose token usage;
those fields must stay null. Inference temperature is recorded; scheduling seed is
not falsely advertised as a provider sampling seed.

The mock deliberately ignores metadata, selects from public question phrases and
uses the first allowed view. It is not calibrated to answerability or reference
labels. The explicit rule router uses operation requirements, public source
preconditions and a small question parser; it has no task-ID or reference lookup.
Its construction/maintenance labor is unmeasured and reported separately.

## Independent evaluation

Reuse the rational/SVD references privately. Separately record correctness,
answerability, provenance, operation selection, arguments, selected-view sufficiency,
avoidable adaptive view error, approximate-result interpretation, abstention,
unsupported claims, rejection/recovery counts, tokens and latency. A forced fixed
view's insufficiency is not an avoidable routing error. Adaptive abstention is
appropriate only if no authorized view can answer. Wrong operations or arguments
cannot receive accidental numerical credit. Source-wide missing evidence is distinct
from a poor representation choice.

Diagnostics are behavioral checks, not access to hidden reasoning. Free-text reasons
are retained but not treated as proof. Temporal cases distinguish zero, missing,
gap and interval totals. Source-size loss, exact versus approximate geometry and
citation support have independent deterministic criteria. Science validity here is
synthetic contract/evidence validity, never expert ecological gold.

Average repetitions within each task before paired M1−M0 and M2−M0 contrasts. Report
first proposed and final supported operation-selection accuracy separately, together
with absolute rates and known-usage denominators, failures and negative results. The small
selected, overlapping synthetic case set does not justify population confidence
intervals or significance claims. No post-outcome cell removal or reference editing.
