# Generated semantic-discovery fixtures

`sentinel_source.json` is generated metadata, not a retrieved source record. Its
historical Sentinel item identifier and documented B08 coefficients demonstrate
native evidence extraction. Access URIs are intentionally nonresolving example.invalid
locations. No pixels, data download, calibration, approved mapping or review decision
are supplied. The fixture license does not license real Sentinel observations.

`concepts.json` contains explicitly synthetic URN concepts and a broader relation.
They are not ENVO concepts, verified scientific definitions or approved mappings.
Both files are tiny offline fixtures under CC0-1.0 for repository contract tests.
