# Synthetic fixtures

All observation records and catalog metadata here are project-authored synthetic
examples dedicated under CC0-1.0. They contain no NEON/Sentinel provider data and
do not reproduce native provider schemas. They test normalized module contracts.

`neon/observations.json`: three invented field canopy-height values.
`sentinel/observations.json`: three invented satellite NIR-reflectance scalars.
`catalog.json`: typed metadata, checksums, sensor/platform, support and rights.

The deliberately equal supports are an architecture simplification, not a claim
that field plots and satellite pixels are equivalent. Other source types and
native-schema-compatible fixtures remain planned. Do not bulk-download source data.
